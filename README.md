# Explainable-AI-XAI-For-Forensic-Decision-Support
Source code and dataset information for my dissertation on Explainable Artificial Intelligence for Forensic Decision Support

This repository contains the source code used for my dissertation,
**"Explainable Artificial Intelligence for Forensic Decision Support."**

## Repository Structure

- `code/` – Source code and Jupyter notebooks used in the study.
- `data/` – Dataset information and source.
- `requirements.txt` – Python libraries required to run the code.

## Dataset

This study uses the IoT-23 dataset. Due to the size of the dataset,
the data files are not included in this repository.

Dataset information and download instructions are available in the
`data/` directory.

## Methods

The project implements machine learning and Explainable Artificial
Intelligence (XAI) techniques, including:

- Random Forest
- XGBoost
- SHAP
- LIME
- Binary classification
- Multiclass classification
